# Scene 一天续航报告设计

## 目标

让用户从 Agent 页面选择一个 Scene 导出的 CSV 文件，得到一份可附带给本地或云端分析的、可追溯的一天续航摘要。

## 范围

首版只读取文本 CSV，不申请存储权限；系统文件选择器授予一次性读取权限。导入器识别常见中英文表头：时间、电量、温度、电流、功耗、前台应用。不能可靠识别的列保留为“未识别”，不参与结论。

## 数据模型

`SceneCsvParser` 将 UTF-8/UTF-8 BOM CSV 转成 `SceneSample` 列表。每条样本可含 `timestampMillis`、`batteryPercent`、`temperatureCelsius`、`currentMilliAmp`、`powerMilliWatt` 和 `foregroundApp`。解析器跳过空行与无有效指标的行，并返回列识别结果和用户可读错误。

`SceneReportBuilder` 从样本计算时间覆盖范围、电量变化、平均/最高温度、平均功耗、平均电流及最常出现的前台应用；只有至少两条带时间和电量的样本才输出耗电速率。所有速率说明其基于导入样本，不作为电池健康或更换电池结论。

## 交互与数据流

Agent 报告选择器中的 Scene 按钮打开系统文件选择器。导入成功后显示文件名与摘要，用户可移除；选中 Scene 后，在线模型将收到生成的文本摘要，本地分析会先在对话中显示同一摘要。导入失败时停留在当前会话，显示可操作原因。

## 错误处理

拒绝空文件、缺少可识别指标、CSV 引号不闭合和没有有效样本的输入。对未知列、缺失时间或只有单个电量样本降级输出，不推断全天续航、实际亮屏时长、应用后台耗电或电池寿命。

## 测试

对 CSV 解析、BOM、中文表头、无效行、错误 CSV、耗电速率、温度统计及无证据降级分别编写 JVM 单测。最后运行全部单测、Lint 和 Debug 构建；在设备上确认能选取 CSV、查看摘要、移除文件并发送报告。
