# 本地报告与分享预览版

- 设备首页提供电池、发热、设备三种本地报告，无需 API Key；单次快照不作换电池结论。
- 分享先展示 PNG 预览，再打开 Android 分享选择器。仅包含机型、时间、所选主题读数与项目地址，不包含应用列表、CSV 或密钥。
- 底部五项导航，统一标题、全宽卡片、参数对齐、青色主题和系统明暗模式。
- Debug ID 为 com.aegis.apa.preview，名称 APA Preview，与正式版并排安装。

当前没有连接设备或 AVD，未执行实机 UI 与分享选择器测试。此前生成的品牌图片和设计稿是参考，当前 APK 尚未完整还原其模型图标与全部卡片样式。

手工验收：无 Key 切换报告主题，生成并核对预览，打开分享选择器后取消；检查小屏、大字号、明暗模式和 Agent 键盘遮挡。
